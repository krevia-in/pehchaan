# Licensing

pehchaan is dual licensed.

## AGPL-3.0-only (default)

Free for any use, including commercial, on one condition: if you modify it, or
run it as part of a network service, the source of that work has to be
available under the AGPL too.

This is fine for internal tools, research, and anything you already open
source.

## Commercial licence

Most companies cannot ship AGPL code inside a closed product, and most will not
open source a service that depends on it. If that is you, a commercial licence
removes the copyleft obligation.

It also comes with the things the open library deliberately leaves out:

- OCR for scanned KYC documents and forms
- Name and address extraction tuned for Indian data
- A maintained UPI handle list and state code table
- Column name pattern packs built from real estates
- Support, and written indemnity

Contact: licensing@krevia.in

## Why AGPL and not MIT

MIT would let a vendor take this, wrap it, and sell it back to the same market
without contributing anything. AGPL does not stop anyone from using it. It
stops someone from building a closed competitor out of it.

If you are an individual, a student, or a team doing internal work, nothing
here applies to you. Take it and go.
